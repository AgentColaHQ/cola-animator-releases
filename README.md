# Cola Animator Beta

Cola Animator is an animation program that works the way Flash did. It is made by Agent Cola HQ.

This is a beta, which means it is a test version. You may find bugs. Please save your work often.

## Download

Go to the [latest release](https://github.com/AgentColaHQ/cola-animator-releases/releases/latest) and download the file for your computer.

| Computer | File to download |
| --- | --- |
| Windows | The file that starts with **Cola-Animator-Setup** and ends with **.exe** |
| Linux | The file that ends with **.AppImage** |
| Mac | Coming later |

You do not need the other files. Cola Animator uses them to update itself.

## Install on Windows

1. Run the Setup file you downloaded.
2. If Windows says "Windows protected your PC," click **More info**, then **Run anyway**. Windows shows this message because Cola Animator is new.
3. Follow the steps in the installer.

## Run on Linux

1. Download the .AppImage file.
2. Allow the file to run. Right-click it, open **Properties**, and turn on **Allow executing file as program**. You can also run this in a terminal: `chmod +x Cola-Animator-*.AppImage`
3. Double-click the file to open Cola Animator.
4. If it does not open, your system may need the **libfuse2** package.

## Updates

Cola Animator checks for a new version each time it starts. When a new version is ready, a bar appears. Click **Restart to Update**.

## Report a bug or suggest a feature

- In Cola Animator, click **Report a Bug** or **Suggest a Feature**. Both buttons are on the start screen and in the Help menu.
- You can also email **hq@agentcolahq.com**.

Please tell us what you clicked, what you expected, and what happened instead. A screenshot helps.
